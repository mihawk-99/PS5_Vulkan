# vertex and instancing. The driver programs the instance count with the AGC
# library's own packet (sceAgcDcbSetNumInstances) immediately before the draw
# and puts it back to one after it -- the order ps5-opengl's runtime uses

#

# vertex shader moves each instance sideways by 0.6 of NDC space and colours it
# by gl_InstanceIndex: one instance must fill the left fifth of the target and
# leave the middle and right fifths clear, and three must fill all three with
# their own colours (src/diagnostics.cpp, run_vulkan_instance_frames).
#
# Risk: low. The frames are the M2 battery's own indexed square, one draw
