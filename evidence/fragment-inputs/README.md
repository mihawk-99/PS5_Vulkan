# Fragment input locations

Run `bash tools/build-psbc-ps5.sh`, `bash tools/build-driver.sh`, then
`bash tools/check-fragment-inputs.sh`. The regression is also part of
`tools/check-driver.sh`. Before the fix, two inputs compile successfully but
produce no input semantics and unresolved AGC linkage. Afterward locations 0/1
map to semantics 15/16, and sparse locations 3/7 map to 18/22 in dense hardware
slots. Rebuild RetroArch against these archives and run its `tools/run-title.sh`
for the target reproduction. Temporary readback instrumentation is parked in
`../PS5_RetroArch/parked/gpu-readback/`; raw captures are ignored there.

`capture.json` contains the machine-readable host/console results and SHA256s.
The shader itself is generated by the regression script; no SDK source or
binary fixture is modified or vendored by this change.
